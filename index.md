### AudioStream is an audio solution for Unity based on FMOD
- [AudioStream _--====--_](https://assetstore.unity.com/packages/tools/audio/audiostream-65411?aid=1100l7sC8) - a Unity package that provides input and output audio streaming ([documentation is also available here](https://github.com/r618/AudioStreamDocs))
- For support, [please use the Unity forums](http://forum.unity3d.com/threads/audiostream-an-audio-streaming-solution-for-all-and-everywhere.412029/).

### AudioStreamIce is a complete Unity SHOUTcast/Icecast client with deep iOS support
- Plays supported audio formats from both cloud and local sources
- Asset Store: [= AudioStreamIce =](https://assetstore.unity.com/packages/slug/223601?aid=1100l7sC8); [documentation is also available here](https://github.com/r618/AudioStreamIceDocs)
- For support, [please use the Unity forums](https://forum.unity.com/threads/audiostreamice.1289045).
- Also available on Itch: [= AudioStreamIce =](https://r618.itch.io/audiostreamice)

### AudioStreamNetCode - client/server audio solution for Unity
- Based on Unity's Netcode for GameObjects networking transport
- Asset Store: [= AudioStreamNetCode =](https://assetstore.unity.com/packages/slug/233329?aid=1100l7sC8), [latest documentation](https://github.com/r618/AudioStreamNetCodeDocs/tree/master)
- For support, [please use the Unity forums](https://forum.unity.com/threads/audiostreamnetcode-network-audio-based-on-netcode-for-gameobjects.1318635/).

### AudioStreamSpeechCerulean - Unity-friendly speech recognition/synthesis via Microsoft Azure Cognitive Services

- Asset Store: [o AudioStreamSpeechCelurean o](https://assetstore.unity.com/packages/slug/247489?aid=1100l7sC8), [latest documentation](https://github.com/r618/AudioStreamSpeechCerulean_Docs)
- For support, please use the [Unity forums](https://forum.unity.com/threads/in-development-audiostreamspeechcelurean.1388841/).
